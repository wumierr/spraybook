## 二、P0 已交付清单

- **M0**：spraybook 建仓（main+calculator-only 推送 GitHub）、老项目归档（README 迁移说明+脚本改指 calculator-only+dry-run 验证）、文档四件套（requirements/PLAN/api/sync-design）+ exportJSON 真实样本。
- **M1**：五层 24 表 001_init.sql + 16+1 科目 seed + 002 追加迁移（验证"只增不改"）+ db:reset + 迁移测试。
- **M2**：POST/GET/PATCH /api/jobs（幂等 client_job_id、job_no 冲突重生成回传、客户 upsert 只建不改、物理量只读权界）+ CORS + 静态白名单。
- **M3**：js/sync.js 同步状态机（探测门/退避 1-5-30 分/10 次转 dead/失败不阻塞/积压告警/混合内容提示）+ 工单面板同步按钮与顶栏徽标 + SW 放行 /api、/ledger + CACHE_VERSION v4.6.0。
- **M4**：结算服务（生成/编辑分项/确认/撤回红冲/作废）+ 账单（部分收款状态机、未收可改金额与抹零）+ 复式记账引擎（过账平衡断言/红冲不删原分录）+ ledger 后台八页签 UI。
- **M5**：收款（部分收款/预收抵扣/核销回退）、支出（油费/药费/维修/吃饭/设备/人工/其他，支持从预支付款）、预收预支（余额/抵扣/冲销/作废保护）、手工分成；全部自动分录+作废反向分录。
- **运维**：`启动spraybook服务.bat` + `npm run db:backup`（在线一致备份，保留 30 份）+ docs/OPS.md。

## 三、测试与实测证据

- 计算器 44 例全绿（未动核心逻辑的回归证据）
- sync 14 例（离线探测门：断网不累加 attempts，可排队任意天数）
- ledger-core 6 例（纯函数：格式化/状态机/平衡标记）
- 服务端 28 例（迁移 7 + jobs API 10 + 结算/财务全链路 11，含：工单→结算→确认→账单→部分收款→作废收款回退→红冲核对→预收抵扣→预支付款→分成→吊运结算）
- 浏览器实测（IAB）：工单→生成结算→确认（原生 confirm 二次确认）→3 张账单→分录 V20260929-001 借贷平衡 ✓→部分收款 100 元→状态"部分收款"→支出登记→汇总条实时联动；截图视觉检查通过
- 端到端冒烟：样本作业 POST→幂等重放 duplicated=true→农户自动建档（source=calculator）

## 四、已知限制（P0 有意为之）

1. 收款挂单张账单；跨账单自动核销、客户级余额在 M6。
2. ledger 无登录（仅局域网）；operator 固定 'local'（M7 补设置页）。
3. jobs 物理量不可在后台改——改错走"计算器更正重传新单 + 旧单作废"。
4. 吊运作业无客户字段，生成结算时在后台指定客户。
5. 分成=手工登记（5007 科目），非自动分账引擎。
6. 报表只有顶部简版汇总；盈利按作业/客户/月在 M6。

## 五、上线前必须完成（后续批次）

1. **M5.5 上线衔接**：历史"未清账"期初导入（未收欠款→期初应收；未用预收→advances），期初凭证借贷平衡，定切换日 T 并逐户对账——**不做这步，新系统第一天所有客户零余额，账就是错的**。
2. M6 报表（盈利按作业/客户/月、欠款/预收余额、跨账单核销）
3. M7 主数据后台 CRUD + 计算器读反哺（历史价格/用药/财务状态）
4. M8 历史 Excel 导入（规则解析为主、LLM 兜底）
5. M9 收尾（bat 菜单整合、README、公网部署重规划、APK 回归）

## 六、怎么跑起来（30 秒版）

1. 双击 `启动spraybook服务.bat`
2. 记账后台：浏览器开 `http://127.0.0.1:8080/ledger/`
3. 现场手机（同 Wi-Fi）：`http://<电脑IP>:8080/`，配置 localStorage 开同步（见 OPS.md 第 2 节）
4. 计算器完成作业→复制工单→后台工单页出现→生成结算→确认→账单→收款
