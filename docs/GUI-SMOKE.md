# GUI 冒烟清单(10 分钟人肉版)

每次发布/改版后过一遍。前置:`1-启动服务并打开网页.bat`。按序执行,任何一步失败即停下记录。

## 计算器(2 分钟)
1. ☁️ 按钮 → 填服务器地址 → **测试连接** → 显示"✓ 连接成功" → 保存。(P6-M1 新增;连不上说明服务没起或地址错)
2. 地块 1 改 8 亩 → **开始计算** → 总收入 = 8 × 每亩收费。
3. **生成工单** → 农户结算表有行 → **同步到账本** → toast "作业已入队"→ 数秒内"已同步"或队列标记成功。

## 记账总表(3 分钟)
4. 打开 `/ledger/` → 默认落在**总表**;顶部数据条当日收入=刚同步的单额(未结算时显示"快照 X(未入账)"是正常的,结算后变账单口径)。
5. 总表行 → **详情** → 地块明细/分家明细有数据。
6. 表头右缘**拖拽**任一列宽 → F5 刷新 → 宽度保持。

## 走账(3 分钟)
7. 工单页 → **生成结算** → 结算页 → **确认**(弹窗点确认)。
8. 账单页 → **登记收款**(默认全额) → 状态"已收清";顶部"已收"不再是 "—"。
9. 支出页 → 登记 80 元 → **编辑本页**改金额 → 保存后**界面应立刻回到非编辑态**(P6 F4 修复验证)。

## 图表与导出(2 分钟)
10. 图表页 → 12 张卡有数据(新库少数据时 C11/C12 显示"暂无数据"正常) → 每图旁 周/月/季/年 可点,x 轴是"1月/W05(01-26)"式人类标签。
11. 总表 → **⬇ 导出CSV** → Excel 打开中文不乱码。

## 已知无害现象
- 未点确认的浏览器原生 confirm 在自动化环境会被跳过;人工环境会弹窗,点确定即可。
- 周编号为 `%W` 周一起 W00(非严格 ISO 周),跨年首周标注 W00。
